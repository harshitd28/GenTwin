Overview

GenTwin Platform

GenTwin is a five-layer Generative Industrial Immunosystem that closes the loop from live sensor anomaly to physics-validated recovery plan in under 1.25 seconds. TwinGuard Dynamics deploys GenTwin at the edge for cement, steel, paper, and hydraulic facilities running OPC-UA SCADA.

Unlike ML classifiers that output labels only, or digital twins that lack autonomous remediation, GenTwin delivers operator-ready SOPs and PLC scripts with zero HAZOP violations across 100 independent trials.

Architecture

Five-Layer Pipeline

Layer 2 gates 82.9% of cycles before any LLM call. Layer 4 operates independently of ML — catching 50/50 adversarial unsafe artifacts.

Layer 1

Sense — IIoT Ingestion

OPC-UA via Telegraf at 5s cadence, cycle-averaged to 60s windows. Sensors: PS1, PS2 (bar), TS1, TS2 (K), Torque (Nm), Speed (rpm), Tool Wear (min). Latency: 3.1 ± 0.4 ms. Storage: InfluxDB.

Layer 2

Detect — Two-Stage ML

Stage 1 Random Forest (<12ms, 95% recall). Stage 2 XGBoost classifies TWF, HDF, PWF, OSF, RNF. Combined latency 28ms. faultCode bridges to ChromaDB.

Layer 3

Generate — RAG + Agent Swarm

ChromaDB with all-MiniLM-L6-v2, θ=0.75. Five agents: Engineer, Simulation, Safety, Cost/Risk, Planner (Gemini 2.5 Flash). Retrieval 312±28ms; synthesis 741±94ms.

Layer 4

Validate — HAZOP + KG

networkx topology graph. Hard limit: PS1 ≤ 130 bar. Latency 38±5ms. FAIL loops to L2; operator never sees unsafe plans.

Layer 5

Act — Operator Interface

Outputs: SOP, PLC JSON, STL (future), emergency shutdown (safetyPriority=3, no LLM). See operator.html.
