L1 · Sense
IIoT Sensor Ingestion

100 Hz telemetry from pressure sensors PS1, PS2 and temperature sensors TS1, TS2 is ingested via OPC-UA Telegraf, cycle-averaged into 60-second windows, and z-score normalised. Additive Gaussian noise injection at σ=0.05 validates robustness under real factory vibration conditions.

Cadence 100 Hz
Protocol OPC-UA
Window 60s
Noise tolerance 5%
L2 · Detect
Two-Stage Ensemble ML

Stage 1 Random Forest (n=100, balanced weighting) screens the full stream in under 12ms, prioritising recall — a missed fault costs more than a false alarm. Stage 2 XGBoost fires only on Stage-1-confirmed anomalies, emitting a typed faultCode that gates downstream RAG retrieval and eliminates redundant LLM calls on normal telemetry.

Stage 2 <16ms

L3 · Generate
RAG Reasoning Engine

The faultCode joins ChromaDB-indexed OEM SOPs, narrowing the vector search space by ≈80%. The all-MiniLM-L6-v2 transformer embeds plant manuals into a 384-dimensional space. Five specialist agents — Engineer, Simulation, Safety, Cost/Risk, Planner — collaborate before synthesising a structured JSON recovery artifact via Gemini 2.5 Flash. Layer 3 is LLM-agnostic; substitutable with Llama-3-8B-Instruct 4-bit GGUF.

L4 · Validate
Physics-Constrained DT Validator

Every generated artifact is validated against a physics-encoded knowledge graph and Monte Carlo degradation model before transmission. Cascade probabilities P=0.84 (Bearing B2→Drive Shaft) and P=0.91 (Drive Shaft→Kiln Motor) represent 85th-percentile outcomes. Layer 4 independently caught 100% of adversarial physically-unsafe plans in 50 adversarial test cases — operating entirely independently of the ensemble classifier.

L5 · Act
Operator Action Interface

Validated JSON artifacts are routed to the operator SCADA as human-readable SOPs, PLC control scripts, or 3D STL print files. Events with safetyPriority=3 bypass the LLM entirely via a hardcoded deterministic shutdown path — no generative component is invoked for critical-shutdown events. Mean time from sensor flag to validated PLC JSON: under 1.25 seconds.
